# Soup For Thought
Gemini-powered recipe generator tailored for local soup kitchens, which often can't predict the type and amount of ingredients received, to reduce food waste.

## What it does
Choose the ingredients you have and how many people you’re serving to generate practical, affordable recipes with flexible substitutions. Designed to support local soup kitchens and reduce food waste when ingredient availability is unpredictable.

## Technologies

- Frontend: React
- Backend: Flask (Python)
- Data Processing: Pandas on RecipeNLG
- AI: Gemini 1.5 Flash for intelligent analysis
